# בדיקה ידנית לפני מיזוג — צ'קליסט לכל פיצ'ר

הבדיקות האוטומטיות מוודאות שהקוד נכון. הצ'קליסט הזה מוודא **שהמוצר עובד** — שהמסכים מובנים,
שהזרימה הגיונית ושההודעה ללקוח נשמעת טוב. כ-30 דקות לכל הפיצ'רים.

## שלוש שכבות, מי אחראי על מה

| שכבה | מה היא תופסת | איך מריצים | מתי |
|---|---|---|---|
| **1. אוטומטית** | באגים בלוגיקה, הרשאות, בידוד בין עסקים, סכומים, תאריכים | `scripts/qa.sh` (או `--fast`) | כל commit — אני מריץ |
| **2. QA עצמאי (סוכן)** | מה שהמפתח לא חשב עליו: קלט זדוני, לחיצות במקביל, API מול מסך | סוכן ברקע, דו"ח ל-`docs/qa/` | כל פיצ'ר גדול / לפני מיזוג |
| **3. ידנית (אתה)** | "האם זה מובן ושימושי", ניסוחים, מראה בטלפון | הצ'קליסט הזה | לפני כל מיזוג ל-main |

## הכנה (פעם אחת)

1. פותחים `http://localhost:5173` ומתחברים עם `local-qa@craftmind.test`.
2. **חלון גלישה בסתר נוסף** = "הלקוח". דפי הלקוח לא דורשים התחברות — כך רואים בדיוק מה הוא רואה.
3. ללקוח שבודקים עליו שמים **את מספר הטלפון שלך** (למשל 050-XXXXXXX), כדי שהוואטסאפ ייפתח אליך ולא ללקוח אמיתי.
4. כדאי לבדוק גם בטלפון: DevTools ← מצב מכשיר נייד (הלקוח כמעט תמיד בטלפון).

סמן ✅ / ❌ ליד כל שורה. ❌ — צלם מסך ושלח לי.

## 1. תדריך הבוקר ורשימת "השבוע הראשון" (מסך "סקירה")

- [ ] בראש המסך: שלושה כרטיסים — **היום**, **דורש תשובה**, **כסף שמחכה לך**.
- [ ] "דורש תשובה" מציג את מסעדת הגליל עם ההערה שלה; לחיצה פותחת את המשימה.
- [ ] "כסף שמחכה לך": סכומים משוערים מסומנים "כ-"; שורת "מגיע לטיפול" בלי היסטוריה מציגה כמות **בלי** סכום.
- [ ] לחיצה על כל שורת כסף מובילה למסך הנכון (הצעות / חשבוניות / מגיע לטיפול).
- [ ] כרטיס "מה CraftMind עשה בשבילך השבוע" מופיע, ומציג רק דברים שקרו.
- [ ] **עסק חדש:** הרשמה כעסק חדש (או משתמש בעסק ריק) ← רשימת 4 הצעדים מופיעה, 0 מתוך 4.
      הוספת פריט מחירון ← חזרה לסקירה ← 1 מתוך 4, והצעד מסומן.
- [ ] ✕ בפינת הרשימה מסתיר אותה, והיא לא חוזרת ברענון.
- **שאלה לשפוט:** האם הייתי פותח את המסך הזה כל בוקר? מה חסר כדי שכן?

## 2. קישור מעקב ללקוח + וואטסאפ

- [ ] משימה פתוחה ← כרטיס "מועד ביקור" ← קובעים התחלה וסיום ← "שמירת מועד".
- [ ] "שליחה ללקוח ב-WhatsApp" ← רואים את ההודעה לפני השליחה ← "פתיחה ב-WhatsApp" נפתח אצלך.
- [ ] **ההודעה:** בלי שם מלא של הלקוח, השעות בסדר הנכון ("בין 10:00 ל-12:00"), נשמעת טבעית.
- [ ] מעתיקים את הקישור ← פותחים **בחלון הבסתר**: שם העסק, המועד, שלבי העבודה. אין טלפון/כתובת.
- [ ] "מאשר/ת את המועד" ← בחזרה אצל בעל העסק: "הלקוח אישר את המועד".
- [ ] במשימה אחרת: בדף הלקוח "מועד אחר" + הערה ← מופיע בסקירה תחת "דורש תשובה".
- [ ] קובעים מועד חדש ← הבקשה נעלמת מ"דורש תשובה".
- [ ] "בדרך" ← דף הלקוח מתעדכן ל"בדרך אליך".
- [ ] **קצוות:** מוחקים תו אחד מהקישור ← "הקישור אינו בתוקף". לקוח בלי טלפון ← אין כפתור וואטסאפ, יש "העתקה".

## 3. ציוד וטיפול תקופתי

- [ ] לקוח ← כרטיס "ציוד" ← הוספת מזגן עם "טיפול אחרון" לפני 7 חודשים, "טיפול כל 6 חודשים".
- [ ] מסך "מגיע לטיפול" ← המזגן מופיע, עם כמה ימים באיחור.
- [ ] "תזכורת לטיפול" ← הודעת וואטסאפ עם קישור ← אחרי שליחה: "נשלחה תזכורת".
- [ ] פותחים את הקישור בבסתר ← "קביעת טיפול תקופתי" ← בוחרים עד 3 מועדים + הערה ← "הבקשה התקבלה".
- [ ] אצל בעל העסק: נוצרה משימה חדשה (מקור: קישור לקוח), והמזגן **נעלם** מ"מגיע לטיפול".
- [ ] פותחים שוב את אותו קישור ← "כבר נקבע" / לא בתוקף (חד-פעמי).
- [ ] סוגרים את המשימה ← בכרטיס הציוד "טיפול אחרון" = היום.
- [ ] **קצוות:** אי אפשר לבחור תאריך שעבר או יותר מחודשיים קדימה. תזכורת שנייה כשיש משימה פתוחה ← נחסמת.

## 4. הצעות מחיר

- [ ] "הצעות מחיר" ← "הצעה חדשה" ← מקלידים 2 אותיות משם לקוח ← בוחרים ← **(כאן היה הקריסה — לוודא שלא)**.
- [ ] מסמנים 2–3 עבודות מהמחירון ← הסכום מתעדכן ← "יצירה ושליחה" ← חלון וואטסאפ.
- [ ] **לחיצה כפולה מהירה** על "יצירה ושליחה" ← נוצרת הצעה **אחת** ברשימה.
- [ ] בבסתר: פירוט, סה"כ, "בתוקף עד". "אישור ההצעה" ← מבקש אישור שני עם הסכום ← "כן, מאשר/ת".
- [ ] אצל בעל העסק: סטטוס "אושרה", ונוצרה משימה שהצ'קליסט שלה = העבודות שבהצעה.
- [ ] בסקירה: "הצעה שאושרה ועוד לא תואמה" עם הסכום. קובעים לה מועד ← השורה נעלמת.
- [ ] הצעה אחרת ← בבסתר "לא עכשיו" ← סטטוס "נדחתה".
- **שאלה לשפוט:** האם לקוח אמיתי היה מבין מה הוא מאשר?

## 5. רווחיות ועלויות מלאי

- [ ] "מלאי" ← לפריט: עלות ליחידה (למשל 35.50) ← נשמר בעמודת העלות.
- [ ] סוגרים משימה עם צריכת 2 יחידות מהפריט ← "רווחיות" ← "החודש": הכנסה, עלות חלקים 71.00, רווח גולמי.
- [ ] חלק בלי עלות ← אזהרה "הרווח בפועל נמוך מהמוצג" + קישור למלאי.
- [ ] לשוניות "סוג עבודה / טכנאי / לקוח" עובדות; שני לקוחות באותו שם = שתי שורות.
- [ ] החלפת תקופה (חודש שעבר / 90 יום) עובדת.

## 6. הרשאות — טכנאי (5 דקות, חשוב)

משתמש טכנאי מקומי כבר קיים: `local-tech@craftmind.test` (הסיסמה נמסרה בצ'אט; מקומי בלבד).
אין עדיין מסך "צוות" בהגדרות — משתמשים נוצרים ב-`npm run user:create`.

- [ ] כבעלים: משייכים לטכנאי **משימה אחת בלבד**.
- [ ] מתחברים כטכנאי בחלון בסתר: ברשימת המשימות רואים **רק** את המשימה שלו.
- [ ] מדביקים כתובת של משימה אחרת (`/tasks/<id>`) ← "לא נמצא".
- [ ] "רווחיות" / "הצעות מחיר" / "מחירון" ← לא נטען (אין הרשאה).
- **לשפוט:** התפריט עדיין מציג לטכנאי מסכים שאין לו גישה אליהם. להסתיר? (הטכנאי אמור לעבוד מאפליקציית השטח.)
